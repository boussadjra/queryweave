# Social image fonts

These files render social images during the documentation build. They are not sent to readers
or loaded from a font service.

Geist Regular, Geist SemiBold, and Geist Mono Regular come from the
[official Geist repository](https://github.com/vercel/geist-font/tree/10dc7658f13c38a474cde201bb09a4617267545b),
pinned to commit `10dc7658f13c38a474cde201bb09a4617267545b`. The original SIL Open Font License is
included in `OFL.txt`.
