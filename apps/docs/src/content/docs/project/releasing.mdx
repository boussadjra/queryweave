GitHub is [`boussadjra/queryweave`](https://github.com/boussadjra/queryweave). npm is the
`queryweave` org, which owns the `@queryweave/*` scope. Those are independent names: do not move
the git repository to `queryweave/queryweave`.

The Release workflow only runs when `github.repository` is `boussadjra/queryweave`. If GitHub still
shows `boussadjra/query-weave`, rename the repository first or the workflow is a no-op.

Every public package shares one version. `pnpm publish:packages` publishes in dependency order,
skips versions already on the registry, and chooses the dist-tag from the semver prerelease id
(`0.1.0-alpha.1` → `alpha`, a stable `0.1.0` → `latest`). Do not use `changeset publish`; it tags
prereleases as `latest` unless Changesets is in pre mode, and even then the lockstep publisher is
the source of truth.

## Dist-tags

| Version             | Dist-tag | Install                           |
| ------------------- | -------- | --------------------------------- |
| `0.1.0-alpha.N`     | `alpha`  | `pnpm add @queryweave/core@alpha` |
| `0.1.0-beta.N`      | `beta`   | `pnpm add @queryweave/core@beta`  |
| `0.1.0-rc.N`        | `rc`     | `pnpm add @queryweave/core@rc`    |
| `0.1.0` (and later) | `latest` | `pnpm add @queryweave/core`       |

Changesets stay in **pre mode** (`alpha`) until you deliberately leave it. That stops
`changeset version` from turning `0.1.0-alpha.1` into a stable `0.1.0` on `latest`.

Bump without Changesets when you need an explicit jump:

```sh
pnpm version:alpha                          # 0.1.0-alpha.1 → 0.1.0-alpha.2
pnpm version:set -- 0.1.0-beta.0            # start beta
pnpm version:set -- 0.1.0                   # first latest
```

Do not run `pnpm version:set` and `changeset version` for the same release.

## First publish

Trusted publishing is configured on an **existing** package. The nine names are new, so the first
run uses a short-lived granular token. Provenance still comes from GitHub Actions.

If the GitHub repository is still named `query-weave`, rename it to `queryweave` before this, so
`repository.url` in each `package.json` matches what npm will attest.

<Steps>

1. Create a GitHub Actions environment named `release` on `boussadjra/queryweave`.

2. On npm, create a granular token for the `queryweave` org that can publish **new** public
   packages. Expiration should be a day or two. Store it as the repository secret `NPM_TOKEN`.

3. Run the **Release** workflow with `first_publish` checked. It runs `pnpm check:release`, then
   `pnpm publish:packages`. The version is {currentPackageVersion}; the tag is `alpha`.

4. Confirm the tag, not just the version:

   ```sh
   npm view @queryweave/core version
   npm dist-tag ls @queryweave/core
   ```

   You want `alpha: 0.1.0-alpha.1`. `latest` must not point at the alpha.

5. On each package page (`npmjs.com/package/@queryweave/core/access`, and the same for `testing`,
   `browser`, `server`, `node`, `standard-schema`, `vue`, `vue-router`, `nuxt`), add a GitHub
   Actions trusted publisher:

   - Organization or user: `boussadjra`
   - Repository: `queryweave`
   - Workflow filename: `release.yml`
   - Environment name: `release`
   - Allowed action: `npm publish`

6. Require 2FA and disallow tokens on those packages once an OIDC publish has succeeded.

7. Delete `NPM_TOKEN` from GitHub and revoke the npm token.

8. Set the repository variable `NPM_TRUSTED_PUBLISHING` to `true`. Later merges to `main` then
   publish through OIDC, with no token.

</Steps>

## Later releases

A user-visible change needs a changeset in the pull request. Merging to `main` opens a Version PR
that bumps the lockstep version and writes `CHANGELOG.md`. Merging that PR publishes with
`pnpm publish:packages` when `NPM_TRUSTED_PUBLISHING` is `true`.

The Release workflow never runs from a fork or a pull request. The publish jobs request
`id-token: write` only for themselves.

## What this alpha does not include

Transition scheduling, date/JSON/object/tuple codecs, per-parameter omission policy, and server
response contribution are [deferred](/project/roadmap/). Debounce search at the call site. Use
`param.custom` for encodings that have no built-in family yet.
