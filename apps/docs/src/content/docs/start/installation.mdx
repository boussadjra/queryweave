## Requirements

- Node.js 24.18.0 or newer for the Node.js integration and for local development.
- TypeScript 5.5 or newer to get the inferred model types.
- ESM. Every package is ESM-only and declares `"type": "module"`.

## What to install

<Steps>

1. **Always install the engine.**

   ```sh
   pnpm add @queryweave/core@alpha
   ```

   `@queryweave/core` has no runtime dependencies and no framework dependency. It targets
   ECMAScript library types only.

2. **Add the package for the environment that stores the query.**

   ```sh
   # A browser history stack
   pnpm add @queryweave/browser@alpha

   # A web-standard Request, on any server, edge, or worker runtime
   pnpm add @queryweave/server@alpha

   # Node.js request primitives
   pnpm add @queryweave/node@alpha
   ```

3. **Add a framework binding if you want one.**

   ```sh
   pnpm add @queryweave/vue@alpha
   pnpm add @queryweave/vue-router@alpha
   pnpm add @queryweave/nuxt@alpha
   ```

   These are optional. The runtime works without any of them.

4. **Add the test adapter as a development dependency.**

   ```sh
   pnpm add -D @queryweave/testing@alpha
   ```

</Steps>

## Package manager

QueryWeave itself is developed with pnpm, and the documentation uses `pnpm add` throughout. npm,
Yarn, and Bun work the same way; only the command word changes.

## Peer dependencies

| Package                       | Peers                   |
| ----------------------------- | ----------------------- |
| `@queryweave/vue`             | `vue`                   |
| `@queryweave/vue-router`      | `vue`, `vue-router`     |
| `@queryweave/nuxt`            | `nuxt`                  |
| `@queryweave/standard-schema` | `@standard-schema/spec` |

No other package has a peer dependency, and none of them declares a dependency on a validation
library or on a frontend framework.
